## 📖 书籍简介
本书是贴合义务教育科学教育「做中学」领航行动的青少年创客一站式教程，构建**零基础入门 → 硬件编程实战 → 科创竞赛拿奖**完整成长路径。
全书内容分为三大板块：入门篇打下基础、实践篇动手完成硬件项目、竞赛篇冲刺科创大赛。
同时配套 **OpenCode AI硬件驱动开发方案**，手把手教会学生利用AI快速生成、调试Arduino / ESP32底层代码。
